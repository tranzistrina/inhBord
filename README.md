# inhBord

**Общие текстовые доски в реальном времени** на Flask, Flask-SocketIO, HTML, CSS и JavaScript.

## Возможности

- Отдельные доски, которые можно создавать, открывать, переименовывать и удалять.
- Изменения текста транслируются другим участникам этой же доски через Socket.IO.
- Кнопки «Копировать всё», «Вставить всё» и скачивание содержимого в `.txt`.
- Файловое сохранение доски, если она не менялась 10 минут, а также сразу после выхода последнего участника.
- При повторном открытии ранее сохранённая доска загружается с диска.
- Общий лимит JSON-файлов досок по умолчанию 1 GiB, проверяется перед каждой записью; сохранение атомарное.
- Адаптивная главная страница, счётчик участников, слов/символов и хранилища.

## Быстрый запуск

Нужен Python 3.10+.

```bash
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows PowerShell: .venv\\Scripts\\Activate.ps1
pip install -r requirements.txt
python app.py
```

Откройте `http://127.0.0.1:5000`. Для проверки откройте одну и ту же ссылку на доску в двух окнах браузера. Содержимое передаётся в реальном времени.

## Конфигурация

Переменные окружения:

- `INHBORD_DATA_DIR` — каталог, где хранятся файлы досок. По умолчанию `data/boards`.
- `INHBORD_MAX_STORAGE_BYTES` — общий лимит файлов в байтах. По умолчанию `1073741824` (1 GiB).
- `INHBORD_MAX_TEXT_CHARS` — максимальный размер текста одной доски в символах. По умолчанию 2 000 000.
- `INHBORD_SECRET_KEY` — секрет Flask. В продакшене задайте длинное случайное значение.
- `INHBORD_CORS` — разрешённые origin для Socket.IO. Для публичного развёртывания укажите свой домен вместо `*`.
- `PORT` — HTTP-порт, по умолчанию `5000`.

Можно скопировать `.env.example` и экспортировать значения окружения в используемом процессе. Автоматическая загрузка `.env` не включена, чтобы не требовать дополнительных пакетов.

## Сохранение и место на диске

Активные доски живут в памяти процесса. Фоновая задача периодически проверяет время последнего изменения: после 10 минут без изменений данные записываются на диск. Когда последний пользователь уходит, доска сбрасывается на диск и выгружается из памяти спустя короткую паузу. Если память сервера или процесс потеряет активную доску до очередной записи, последние несохранённые изменения могут быть потеряны.

Лимит 1 GiB относится к сериализованным файлам досок в указанном каталоге, а не к свободному месту всего сервера. При достижении лимита запись отклоняется и активный текст остаётся в памяти; интерфейс получает событие об ошибке. Перед эксплуатацией с важными данными настройте мониторинг, резервные копии и постоянный диск.

## Запуск в продакшене

Для небольшой установки можно использовать один процесс с поддержкой WebSocket. Например, `python app.py` за reverse proxy, который проксирует WebSocket. Установленный Gunicorn можно использовать для deployments с выбранным worker, совместимым с Socket.IO; не запускайте несколько независимых worker-процессов без общей очереди сообщений и общего состояния досок. Для масштабирования на несколько процессов потребуется Redis (message queue), общее хранилище и отдельная стратегия согласования состояния.

Перед публичным запуском:

1. Установите секретный ключ и `INHBORD_CORS`.
2. Ограничьте доступ на уровне сети, если доски не должны быть публичными: в этом проекте нет аутентификации, авторизации, приватных ссылок или истории версий.
3. Настройте HTTPS, резервное копирование каталога досок и мониторинг заполнения диска.
4. Не размещайте несколько инстансов приложения без общей координации: по умолчанию синхронизация между пользователями рассчитана на один процесс сервера.


## Ограничения

- Все посетители, знающие адрес доски, могут читать и менять её.
- Совместное редактирование транслирует целую версию текста, не отдельные операции. При одновременном редактировании одного места текста последнее принятое сервером обновление может перезаписать конкурирующее. Для интенсивной одновременной работы лучше использовать CRDT/OT (например, Yjs).
- Кнопки буфера обмена зависят от разрешений браузера; в большинстве браузеров Clipboard API требует HTTPS или localhost.
