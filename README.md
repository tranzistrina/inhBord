# inhBord

**Общие текстовые доски в реальном времени** на Flask, Flask-SocketIO, HTML, CSS и JavaScript.

Проект обновлён с учётом подхода `fileMORDAinh`: конфигурация задаётся переменными окружения, секрет Flask автоматически генерируется и хранится в локальном файле, предусмотрен единый скрипт установки и запуска. Для поддержки Socket.IO используется совместимый потоковый сервер Flask-SocketIO, а не Waitress, который не обслуживает WebSocket upgrade.

## Возможности

- Общие доски с синхронизацией текста между участниками через Socket.IO.
- Создание, открытие, переименование и удаление досок.
- Копирование и вставка всего текста, скачивание в `.txt`.
- Атомарное файловое сохранение и общий лимит хранилища по умолчанию 1 GiB.
- Восстановление сохранённых досок после перезапуска.
- Адаптивный интерфейс, онлайн-счётчик и статистика текста.
- HTTP health check: `/api/health`.

## Быстрый запуск

Нужен Python 3.10+.

### macOS / Linux

```bash
chmod +x run.sh
./run.sh
```

Скрипт создаёт виртуальное окружение `.venv`, устанавливает зависимости и запускает приложение на порту **4568**.

### Вручную

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
PORT=4568 python app.py
```

Откройте `http://127.0.0.1:4568`.

Чтобы подключиться с другого устройства локальной сети, используйте IP компьютера-сервера: `http://IP_СЕРВЕРА:4568`.

## Настройка

- `HOST` — адрес привязки, по умолчанию `0.0.0.0`.
- `PORT` — HTTP-порт, по умолчанию `4568`.
- `INHBORD_SECRET_KEY` — постоянный секрет Flask. Если не указан, генерируется в файле `.session_secret`.
- `COOKIE_SECURE` — `1`, если приложение доступно только по HTTPS.
- `INHBORD_DATA_DIR` — каталог JSON-файлов досок. По умолчанию `data/boards`.
- `INHBORD_MAX_STORAGE_BYTES` — общий лимит хранилища, по умолчанию `1073741824` байт.
- `INHBORD_MAX_TEXT_CHARS` — максимальный размер текста одной доски, по умолчанию 2 000 000 символов.
- `INHBORD_CORS` — разрешённые origin для Socket.IO. Для публичного развёртывания замените `*` своим доменом.

Шаблон переменных находится в `.env.example`. Приложение не загружает файл `.env` автоматически, поэтому экспортируйте значения в окружение процесса либо используйте менеджер сервисов.

## Данные и сохранение

Активные доски хранятся в памяти и атомарно записываются в JSON-файлы. При завершении последнего соединения приложение пытается сохранить доску; бездействующие доски сохраняются фоновой задачей. Данные находятся в `data/boards` (или в `INHBORD_DATA_DIR`) и не должны включаться в Git.

Не запускайте несколько независимых экземпляров приложения с одним хранилищем: состояние живых Socket.IO-досок находится в памяти конкретного процесса. Для нескольких процессов потребуется общая очередь сообщений и стратегия согласования состояния.

## Важные ограничения безопасности

- Доски не защищены аутентификацией: любой, кто знает URL доски, может её читать и менять.
- Для публичного доступа задайте секретный ключ, ограничьте `INHBORD_CORS`, настройте HTTPS и резервное копирование.
- Не открывайте сервис в интернет без сетевых ограничений или reverse proxy с HTTPS.
- При одновременном редактировании одного фрагмента текста действует модель «последний принятый снимок». Для продвинутого совместного редактирования понадобится OT/CRDT, например Yjs.

## Структура

```text
app.py                  # Flask routes, Socket.IO events and persistence
run.sh                  # one-command environment setup and start
templates/index.html    # home page and board editor
static/css/style.css    # responsive UI
static/js/app.js        # board list, editor and clipboard controls
data/boards/            # persisted boards (excluded from Git)
```
